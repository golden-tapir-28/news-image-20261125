# THE WORLD — Wednesday 25 November 2026

Front page of **THE WORLD** for Wednesday 25 November 2026: 35 verified
stories from 7 regions plus 11 briefs, rendered as a single 1024x1024
newspaper image by `main.py` (Python 3.13, standard library only, with
a headless-Chromium screenshot and a Pillow fallback).

Lead story: Putin vows "inevitable" retaliation as Ukraine's war spills
into the Baltic — after Kyiv keeps striking Russian refineries, drones
hit the cargo ship Sparta II in the Gulf of Finland and a warship off
Benghazi, and a Russian night attack on Zaporizhzhia kills two civilians
and wounds 44.

## How it works

`python3 main.py` builds the front page as self-contained HTML and
screenshots it at 1024x1024 with a headless Chromium binary (or renders
it with Pillow if no Chromium is available), writing `entry.png` to
`./entry.png` — or to `$MAKEFUN_OUTPUT_DIR/entry.png` when that
variable is set. The render is deterministic: the same inputs always
produce the same PNG. Type is auto-scaled to fill the page (verified
at scale 0.74, two runs byte-identical, 355,476 bytes).
